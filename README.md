# ColorNote Notepad Notes (Flutter)

A complete Flutter application merging **ColorNote Notepad Notes** & **KiteTech Simple Notepad Notes** capabilities.

## Features
- **Dual Note Types**: Lined text notes and checklist/to-do lists.
- **9-Color System**: Categorize notes with customizable color labels.
- **Search & Sort**: Sort by color, modification date, creation date, alphabetically, or reminder time.
- **Calendar Integration**: View and manage reminders directly on a calendar.
- **Security & Lock**: Protect sensitive notes with a PIN/master password.
- **Archive & Trash**: Safely store or restore notes.
- **Automated CI/CD**: GitHub Actions workflow to build release APKs automatically.

## Getting Started

### Prerequisites
- Flutter SDK (>= 3.2.0)
- Dart SDK

### Installation
```bash
# Clone the repository
git clone https://github.com/Khalifa-Programmer/colornote_flutter.git

# Navigate to the project directory
cd colornote_flutter

# Install dependencies
flutter pub get

# Run the app
flutter run
```
